## Reactiflux Discord (#show-off or #libraries)

Hey! I just released Noor UI — an RTL-first React component library for bilingual apps (English/Arabic). 77+ components built on Radix UI + Tailwind CSS v4. Every component uses logical properties so the UI flips between LTR and RTL automatically.

Comes with 5 real app examples (school portal, clinic, bank, hotel booking) and regional components like Prayer Times and Hijri Calendar.

npm: `npm install noorui-rtl`
Docs: https://noorui.com
GitHub: https://github.com/ositaka/noor-ui

MIT licensed. Would love feedback!

## Tailwind CSS Discord (#showcase)

Built an RTL-first component library using Tailwind CSS v4 (CSS-first config, no tailwind.config.ts). 77+ components, all using logical properties — ms-, me-, ps-, pe-, start, end. Zero left/right anywhere.

4 themes powered by CSS custom properties, dark mode, and it all flips perfectly between English and Arabic.

https://noorui.com | npm: noorui-rtl

## Next.js Discord (#showcase)

Sharing Noor UI — a component library built with Next.js 14 for bilingual (English/Arabic) apps. 77+ components, 4 themes, logical CSS throughout.

Includes 5 full Next.js example apps with App Router: Education Portal, Healthcare Clinic, Digital Banking, Hotel Booking, and more. All fully routed and bilingual.

https://noorui.com | `npm install noorui-rtl`

## Radix UI Discord (if they have a #showcase)

Built a full component library on top of Radix UI primitives with RTL-first support. 77+ components, all with logical CSS properties, tested in both LTR and RTL.

Includes directional fixes for Radix components (Select portal positioning, Dialog close button using `end-4`, Switch thumb with RTL transform variants).
