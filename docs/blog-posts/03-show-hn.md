**Title:** Noor UI – RTL-first React components for bilingual apps (77+ components, Arabic/English)

**Description:**

Noor UI is an open-source React component library built for bilingual applications. Instead of treating RTL as an afterthought, every component is designed with logical CSS properties so the entire UI flips between English (LTR) and Arabic (RTL) without conditional code.

77+ components (Radix UI + Tailwind CSS), 4 themes, 690+ unit tests. Includes regional components (Prayer Times, Hijri Calendar, Zakat Calculator) and experimental AI/LLM components.

Comes with 5 complete application examples: Education Portal, Healthcare Clinic, Digital Banking, Hotel Booking, and more — each fully bilingual with multi-page flows.
