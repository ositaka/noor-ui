# Product Hunt Launch

## Tagline (60 chars max)
RTL-first React components for bilingual English/Arabic apps

## Description
Noor UI is an open-source, RTL-first React component library for bidirectional applications. 77+ accessible components that work perfectly in both English (LTR) and Arabic (RTL) — no conditional logic, no hacks, just logical CSS properties.

Includes regional components for Islamic contexts (Prayer Times, Hijri Calendar, Zakat Calculator), 4 built-in themes, 690+ unit tests, and 5 complete application examples (Education, Healthcare, Banking, Hotel, and more).

Built with Radix UI, Tailwind CSS v4, and TypeScript. MIT licensed.

## First Comment (post this immediately after launching)
Hey Product Hunt! I'm Nuno, a Portuguese developer who spent months building Noor UI.

The problem: most component libraries treat RTL as an afterthought. Arabic developers constantly fight broken layouts, misaligned icons, and reversed animations.

Noor UI is RTL-first — every component uses logical CSS properties (start/end instead of left/right), so the entire UI flips automatically between English and Arabic.

I validated the library by building 5 real apps with it: a Saudi school portal, a healthcare clinic, a digital bank, a hotel booking platform, and more. Each one works in both languages with zero direction-specific code.

Would love your feedback! Especially interested in hearing from developers building for Arabic, Hebrew, or Urdu markets.
