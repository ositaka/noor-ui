# Showcase Video Script

**Target length:** 60-90 seconds (short enough for LinkedIn/Twitter, detailed enough for Product Hunt)
**Format:** Screen recording with minimal text overlays, no voiceover needed (add captions)
**Tool suggestion:** Screen Studio (macOS) or OBS + edit in CapCut/DaVinci

---

## Shot list (in order)

### 1. Open with the Education Portal — English (5s)
- Show the dashboard: stats cards, class schedule, GPA chart
- Quick scroll down to show depth of content

### 2. Click the Arabic toggle (3s)
- Hit the العربية button in the header
- **The magic moment**: entire UI flips to RTL
- Pause for 1 second to let it land

### 3. Education Portal — Arabic (5s)
- Same page, now in Arabic
- Navigation on the right, text right-aligned, icons mirrored
- Everything feels native, not just mirrored

### 4. Switch to Healthcare example (5s)
- Show the appointment calendar with Hijri dates
- Patient profile with bilingual name (Arabic primary, English secondary)
- Donut chart for appointment types

### 5. Flip Healthcare to Arabic (3s)
- Same RTL flip moment
- Calendar shows Hijri months as primary
- Arabic layout feels completely natural

### 6. Quick montage of other examples (8s)
- Banking dashboard (charts, transaction table)
- Hotel booking (carousel, stepper)
- Each with a quick LTR → RTL flip

### 7. Component playground (8s)
- noorui.com/components/button — show variant grid
- Flip to RTL — buttons adapt
- Switch theme (Cozy → Futuristic) — instant visual change

### 8. Storybook (5s)
- Open storybook.noorui.com
- Show RTL toggle in toolbar
- Show theme switcher
- Flip a component

### 9. Install (5s)
- Terminal: `npm install noorui-rtl`
- Code editor: 3-line import and usage
- Text overlay: "77+ components. 690+ tests. 4 themes. MIT licensed."

### 10. End card (5s)
- noorui.com
- github.com/ositaka/noor-ui
- "Built with love by Nuno Marques"

---

## Total: ~55 seconds

## Key moments to nail:
- **The RTL flip is your hero shot.** Make it dramatic — use the Education Portal with the full dashboard visible, click the toggle, and let the camera hold on the result for a beat.
- **Speed**: Don't linger. This is a showcase reel, not a tutorial. Each shot should feel snappy.
- **No voiceover needed**: Use text captions or overlays. The visual speaks for itself.

## Where to use the video:
- LinkedIn post (upload natively, not as a link)
- Twitter/X thread (tweet 5)
- Product Hunt gallery
- YouTube (for embedding on noorui.com homepage later)
- dev.to article (embed YouTube link)
