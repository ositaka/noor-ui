I just shipped Noor UI — an open-source, RTL-first React component library for bidirectional applications.

The problem: most UI libraries treat Arabic (RTL) as an afterthought. Broken layouts, reversed icons, misaligned text.

My approach: RTL-first. Every component uses logical CSS properties. The entire UI flips between English and Arabic automatically — no hacks, no conditional code.

What's included:
- 77+ production-ready components
- Regional & Islamic: Prayer Times, Hijri Calendar, Zakat Calculator
- 4 themes, dark mode, full accessibility
- 690+ unit tests
- 5 complete app examples (Education, Healthcare, Banking, Hotel, more)

It's MIT licensed and free on npm: npm install noorui-rtl

Docs: noorui.com
GitHub: github.com/ositaka/noor-ui

If you're building bidirectional apps for Arabic, Hebrew, Urdu, or Farsi markets — give it a try.
