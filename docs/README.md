# Noor UI — Internal Documentation

For user-facing documentation, visit [noorui.com](https://noorui.com).

This directory contains architecture decisions, development guides, and design process documentation for contributors.

---

## Documentation Structure

### `/architecture/`
Architecture decisions and technical strategies:
- `I18N-SOLUTION.md` — Internationalization implementation approach
- `MULTILINGUAL_STRATEGY.md` — Multilingual content management patterns

### `/development/`
Development guides, processes, and checklists:
- `COMPONENT_CHECKLIST.md` — Component development checklist
- `COMPONENT_DOCUMENTATION_STANDARDS.md` — Documentation standards
- `NPM_PACKAGE_STRATEGY.md` — NPM package structure and strategy
- `PUBLISHING_GUIDE.md` — Step-by-step publishing guide
- `PRE_PUBLISH_CHECKLIST.md` — Pre-publish validation checklist
- `TESTING.md` — Testing guidelines and strategies
- `PERFORMANCE.md` — Performance optimization guide

### `/design/`
Design documentation and UI specifications.

### `/case-studies/`
Design process documents covering how key features were built. Useful for understanding architectural decisions and as source material for blog posts.

### `/initial-prompt/`
The original project specification that defined the architecture, design philosophy, and component requirements for Noor UI.
