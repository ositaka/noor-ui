# Installation

Get NoorUI up and running in your project in under five minutes. This guide covers package installation, CSS configuration, font loading, and provider setup.

---

## 1. Install the Package

Install NoorUI and its peer dependencies using your preferred package manager.

<CodeBlock
  language="bash"
  filename="Terminal"
  code={`# pnpm (recommended)
pnpm add noorui-rtl

# npm
npm install noorui-rtl

# yarn
yarn add noorui-rtl`}
/>

NoorUI requires React 18+ and is designed for use with Next.js 14+, though it works in any React project.

---

## 2. CSS Setup

You have two options for loading NoorUI styles, depending on whether you want quick setup or full Tailwind v4 integration.

### Option A: Pre-compiled CSS (quickest)

Import the pre-built stylesheet at the top of your application entry point. This includes all tokens, themes, and component styles.

<CodeBlock
  language="tsx"
  filename="app/layout.tsx"
  code={`import 'noorui-rtl/styles.css';`}
/>

This is the simplest approach and works well if you do not need to customize the design tokens or extend the Tailwind configuration.

### Option B: Tailwind v4 Integration (recommended)

For full control over tokens and theming, import the NoorUI package CSS alongside Tailwind in your global stylesheet. This approach uses Tailwind CSS v4's CSS-first configuration.

<CodeBlock
  language="css"
  filename="styles/globals.css"
  code={`@import "tailwindcss";

/* Import NoorUI tokens, themes, and base styles */
@import "noorui-rtl/styles.css";

/* Your custom styles below */`}
/>

With this setup, all NoorUI design tokens are available as Tailwind utilities in your own components (e.g., `text-primary`, `bg-muted`, `border-border`).

---

## 3. Font Setup

NoorUI uses three font families: **Inter** for Latin text, **IBM Plex Sans Arabic** for Arabic text, and **JetBrains Mono** for code. Load them via Google Fonts.

### Using CSS @import (any project)

Add these imports at the top of your global CSS file, before any other imports:

<CodeBlock
  language="css"
  filename="styles/globals.css"
  code={`@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap');
@import url('https://fonts.googleapis.com/css2?family=IBM+Plex+Sans+Arabic:wght@400;500;600;700&display=swap');
@import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600&display=swap');`}
/>

### Using Next.js Font Optimization

If you are using Next.js, take advantage of built-in font optimization for better performance:

<CodeBlock
  language="tsx"
  filename="app/layout.tsx"
  code={`import { Inter, IBM_Plex_Sans_Arabic, JetBrains_Mono } from 'next/font/google';

const inter = Inter({
  subsets: ['latin'],
  variable: '--font-inter',
  display: 'swap',
});

const ibmPlexSansArabic = IBM_Plex_Sans_Arabic({
  weight: ['400', '500', '600', '700'],
  subsets: ['arabic'],
  variable: '--font-arabic',
  display: 'swap',
});

const jetBrainsMono = JetBrains_Mono({
  subsets: ['latin'],
  variable: '--font-mono',
  display: 'swap',
});`}
/>

Apply the font variables to your `<body>` element:

<CodeBlock
  language="tsx"
  filename="app/layout.tsx (body tag)"
  code={`<body className={\`\${inter.variable} \${ibmPlexSansArabic.variable} \${jetBrainsMono.variable} font-sans antialiased\`}>
  {children}
</body>`}
/>

## 4. Provider Setup

NoorUI requires three nested providers. The order matters: **DirectionProvider** must wrap **ThemeProvider**, which wraps **IconContext.Provider**.

<CodeBlock
  language="tsx"
  filename="app/layout.tsx"
  code={`import { DirectionProvider } from 'noorui-rtl';
import { ThemeProvider } from 'next-themes';
import { IconContext } from '@phosphor-icons/react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" dir="ltr" suppressHydrationWarning>
      <body className="font-sans antialiased">
        <DirectionProvider>
          <ThemeProvider
            attribute="class"
            defaultTheme="system"
            enableSystem
          >
            <IconContext.Provider
              value={{ weight: 'duotone', color: 'currentColor' }}
            >
              {children}
            </IconContext.Provider>
          </ThemeProvider>
        </DirectionProvider>
      </body>
    </html>
  );
}`}
/>

**What each provider does:**

- **DirectionProvider** -- Manages the `dir` attribute on `<html>`, tracks the current locale (`en` or `ar`), and provides the `useDirection()` hook to all child components.
- **ThemeProvider** (next-themes) -- Handles light/dark mode switching with system preference detection. Uses class-based toggling (`.dark` class).
- **IconContext.Provider** (@phosphor-icons/react) -- Sets default icon weight to `duotone` and color to `currentColor` so icons inherit text color automatically.

## 5. Your First Component

With everything configured, render a NoorUI Button to verify the setup:

<CodeBlock
  language="tsx"
  filename="app/page.tsx"
  code={`import { Button } from 'noorui-rtl';

export default function Home() {
  return (
    <main className="flex min-h-screen items-center justify-center gap-4 p-8">
      <Button variant="primary">Get Started</Button>
      <Button variant="outline">Learn More</Button>
      <Button variant="secondary">Settings</Button>
    </main>
  );
}`}
/>

The buttons will automatically adapt their layout when the direction changes from LTR to RTL -- padding, icon placement, and text alignment all flip correctly.

---

## 6. Verification Checklist

Run through these checks to confirm everything is working:

- **Fonts load correctly** -- Open your browser DevTools, go to the Network tab, and confirm that Inter, IBM Plex Sans Arabic, and JetBrains Mono font files are loaded.
- **Theme switching works** -- If using next-themes, toggle between light and dark mode. The `.dark` class should appear on `<html>` and all component colors should update.
- **Direction toggle works** -- Use the `useDirection()` hook or manually set `document.documentElement.dir = 'rtl'` in the console. All layout properties (`margin-inline-start`, `padding-inline-end`, etc.) should flip.
- **Design theme applies** -- Add a `theme-cozy` class to `<html>` in DevTools and verify that border radii, colors, and spacing change.
- **Icons render** -- Import any Phosphor icon (e.g., `import { Heart } from '@phosphor-icons/react'`) and confirm it renders in duotone style with `currentColor`.

Once all checks pass, you are ready to build. Head to the **Usage Guide** for patterns and best practices.
