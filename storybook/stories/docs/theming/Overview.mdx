# Theming Overview

NoorUI ships with a **5-theme system**: one default theme plus four named themes, each carefully designed for different use cases and visual personalities. Every theme supports both light and dark modes and works seamlessly in LTR and RTL layouts.

---

## The Five Themes

### Default

The base theme applied when no theme class is present. It uses the `:root` CSS custom properties directly -- a clean indigo primary, teal secondary, and balanced neutral palette. The default radius is `0.5rem`, heading weight is `700`, and body line-height is `1.6`. It is the most versatile starting point for general-purpose applications.

### Minimal (بسيط)

Clean design with maximum readability. The Minimal theme strips back visual noise by using subtle grayscale borders, generous white space, and restrained color usage. Key characteristics:

- **Border radius:** `0.25rem` -- tight, rectangular feel
- **Heading weight:** `600` -- semibold rather than bold
- **Letter-spacing:** `-0.02em` on headings -- slightly tighter for a refined look
- **Color palette:** Desaturated neutrals with the default indigo primary retained

Best for content-heavy interfaces, reading applications, and documentation sites.

### Futuristic (مستقبلي)

A dark-optimized theme featuring gradient accents and glassmorphism effects. The Futuristic theme's light mode IS already dark -- it uses a `hsl(240 10% 8%)` background by default. Key characteristics:

- **Border radius:** `0.75rem` -- softly rounded
- **Heading weight:** `600` -- clean semibold
- **Primary color:** Purple (`hsl(270 80% 60%)`) with cyan secondary (`hsl(190 80% 50%)`)
- **Body line-height:** `1.5` -- compact for dashboard-style layouts
- **Letter-spacing:** `-0.025em` on headings, `-0.01em` on body -- tighter for a technical aesthetic

Best for dashboards, data-heavy products, and enterprise tools.

### Cozy (دافئ)

Warm tones with rounded corners and soft shadows. The Cozy theme feels inviting and personal, using amber and earth tones throughout. Key characteristics:

- **Border radius:** `1.25rem` -- generously rounded, the largest of all themes
- **Heading weight:** `700` -- bold for emphasis
- **Primary color:** Warm orange (`hsl(25 85% 55%)`)
- **Body line-height:** `1.7` -- relaxed spacing for comfortable reading
- **Letter-spacing:** `0.015em` on body -- slightly open for warmth

Best for consumer apps, onboarding flows, and interfaces that should feel approachable.

### Artistic (فني)

Typography-focused with elegant serif fonts. The Artistic theme breaks from the sans-serif convention entirely, using Georgia as its primary typeface. Key characteristics:

- **Border radius:** `0.125rem` -- barely rounded, nearly sharp edges
- **Heading weight:** `400` -- light weight for elegant, editorial headlines
- **Primary color:** Deep purple (`hsl(280 60% 50%)`) with golden secondary (`hsl(45 100% 50%)`)
- **Body line-height:** `1.8` -- generous vertical rhythm for long-form reading
- **Font family:** Georgia / Times New Roman for body and headings; Noto Naskh Arabic for RTL
- **Letter-spacing:** `0.02em` on headings, `0.01em` on body -- open tracking typical of serif typography

Best for portfolios, editorial content, poetry, and branding-focused interfaces.

Each named theme carries bilingual metadata defined in `themeConfig` within `lib/tokens.ts`. This includes the theme name, description, and feature list in both English and Arabic:

```typescript

  description: 'Warm tones with softer corners and gentle shadows',
  descriptionAr: 'ألوان دافئة مع زوايا ناعمة وظلال لطيفة',
```

This metadata powers theme pickers, documentation, and any UI that needs to present theme information in the user's language.

## How It Works

The theming system is built on **CSS class-based overrides**. Each theme is a CSS class -- `.theme-minimal`, `.theme-futuristic`, `.theme-cozy`, `.theme-artistic` -- that overrides CSS custom properties on the root element.

The cascade works like this:

1. `:root` defines the default (base) values for all CSS custom properties
2. A `.theme-*` class overrides those properties with theme-specific values
3. The `.dark` class (or `.theme-*.dark` compound selector) overrides again for dark mode
4. Components simply reference semantic tokens like `bg-primary` and `text-foreground` -- they never know which theme is active

Because the override happens at the CSS variable level, **theme switching is instant**. There is no JavaScript runtime cost, no re-renders, and no layout shift. The browser simply recalculates the resolved values of the custom properties and repaints.

### The `applyTheme()` Function

The `applyTheme()` function from `lib/tokens.ts` handles theme switching programmatically:

```typescript
export function applyTheme(theme: Theme, root: HTMLElement = document.documentElement) {
  root.classList.forEach(cls => {
    if (cls.startsWith('theme-')) root.classList.remove(cls)
  })
  root.classList.add(`theme-${theme}`)
}
```

It removes all existing `theme-*` classes from the root element, then adds the new one. This ensures only one theme is ever active at a time.

<DesignDecision title="Why five themes instead of just light and dark?">
  <p>
    Light/dark mode controls luminance, but a theme controls <strong>personality</strong>. The same
    application might need to feel clinical for a healthcare dashboard (Minimal), warm for a consumer
    onboarding flow (Cozy), or expressive for a creative portfolio (Artistic). By separating theme
    identity from color mode, NoorUI lets you choose both independently -- any theme can be light or dark.
  </p>
</DesignDecision>

<DesignDecision title="CSS classes over JavaScript runtime theming" type="tip">
  <p>
    Many design systems implement theming through JavaScript context providers that trigger re-renders across
    the entire component tree. NoorUI's CSS class approach means theme switching is a single DOM operation
    (adding/removing a class). The browser handles the rest through CSS custom property resolution -- no
    React reconciliation, no layout thrashing, no flash of unstyled content.
  </p>
</DesignDecision>
