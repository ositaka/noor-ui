## This Storybook vs. noorui.com

Noor UI has two homes, each serving a different purpose:

| | **[noorui.com](https://noorui.com)** | **This Storybook** |
|---|---|---|
| **Purpose** | Full documentation, guides, and polished examples | Interactive sandbox for exploring components |
| **What you see** | All variants rendered in a live app context | Individual stories with Controls, Actions, and Accessibility panels |
| **Interact** | Read and copy code | Toggle **Direction**, **Theme**, and **Mode** in real time via the toolbar above |
| **Source of truth** | Yes — always up to date | Best effort — some RTL edge cases may differ from the live site |

**Use this Storybook** to experiment with component props, test themes, and see how components behave when switching between LTR and RTL. **Use [noorui.com](https://noorui.com)** for production-ready documentation and guides.

---

## Using the Toolbar

The toolbar at the top of every page lets you switch three global settings in real time:

- **Direction** (LTR / RTL) — flips layout and switches text to Arabic
- **Theme** (Minimal, Futuristic, Cozy, Artistic) — swaps the entire design personality
- **Mode** (Light / Dark) — toggles color mode

Every component in the sidebar responds to these controls instantly. The **Default** story for each component switches to Arabic text in RTL mode. Secondary stories retain English text for reference — toggle direction to verify layout and spacing behavior.

## Quick Start

Install Noor UI and start building:

<CodeBlock
  language="bash"
  filename="Terminal"
  code={`# pnpm (recommended)
pnpm add noorui-rtl

# npm
npm install noorui-rtl

# yarn
yarn add noorui-rtl`}
/>

Import styles and set up providers:

<CodeBlock
  language="tsx"
  filename="app/layout.tsx"
  code={`import 'noorui-rtl/styles.css';
import { DirectionProvider } from 'noorui-rtl';
import { ThemeProvider } from 'next-themes';
import { IconContext } from '@phosphor-icons/react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" dir="ltr" suppressHydrationWarning>
      <body className="font-sans antialiased">
        <DirectionProvider>
          <ThemeProvider attribute="class" defaultTheme="system" enableSystem>
            <IconContext.Provider value={{ weight: 'duotone', color: 'currentColor' }}>
              {children}
            </IconContext.Provider>
          </ThemeProvider>
        </DirectionProvider>
      </body>
    </html>
  );
}`}
/>

For the full setup guide (fonts, Tailwind v4 integration, verification checklist), visit **[noorui.com/getting-started](https://noorui.com/getting-started)**.
