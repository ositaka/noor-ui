## What is NoorUI?

**Noor** (نور) means *light* in Arabic. NoorUI is a production-grade React component library purpose-built for bidirectional interfaces. Where most design systems treat right-to-left support as an afterthought -- a last-minute CSS patch before a regional launch -- NoorUI starts from the other direction entirely.

Every component is authored in RTL first, verified in LTR second, and tested in both. The result is a library that feels native in Arabic, Farsi, Hebrew, and Urdu interfaces while remaining seamless for English, French, and every other LTR language.

NoorUI is built on **Radix UI** primitives for accessibility, **Tailwind CSS v4.1** for styling with CSS-first configuration, and **Class Variance Authority (CVA)** for type-safe variant management.

<DesignDecision title="Why RTL-First?">
  <p>
    Most design systems are built LTR and then "flipped" for RTL. This leads to subtle bugs: misaligned icons,
    incorrect padding, broken animations, and text that feels unnatural. NoorUI inverts this model. By building
    RTL-first, we ensure the hardest layout challenges are solved from the start. LTR support then becomes the
    simple case -- and it works flawlessly because logical properties are direction-agnostic by design.
  </p>
</DesignDecision>

## Themes

NoorUI ships with five carefully crafted themes, each with full light and dark mode support:

| Theme | Character | Best For |
|---|---|---|
| **Default** | Clean, professional, balanced | General-purpose applications |
| **Minimal** | Stripped-back, typographic, quiet | Content-heavy interfaces, reading apps |
| **Futuristic** | Bold gradients, high contrast, neon accents | Dashboards, data-heavy products |
| **Cozy** | Warm tones, rounded corners, soft shadows | Consumer apps, onboarding flows |
| **Artistic** | Expressive, creative, distinctive | Portfolios, branding, editorial |

Themes are applied via CSS class names (`.theme-minimal`, `.theme-cozy`, etc.) and work by overriding CSS custom properties -- no JavaScript runtime cost, no re-renders, instant switching.

## Tech Stack

| Layer | Technology | Role |
|---|---|---|
| **Framework** | React 18+ / Next.js 15 | Component model and server-side rendering |
| **Styling** | Tailwind CSS v4.1 | Utility-first CSS with CSS-first configuration |
| **Primitives** | Radix UI | Accessible, unstyled headless components |
| **Variants** | Class Variance Authority (CVA) | Type-safe component variant management |
| **Language** | TypeScript | End-to-end type safety |
| **Icons** | Phosphor Icons | Flexible, consistent icon system |
