# Shadows & Elevation

Shadows in NoorUI communicate depth and hierarchy. The shadow scale ranges from subtle surface elevation to dramatic floating elements. Each shadow token is defined in the `@theme` block and can be influenced by the active theme and color mode.

---

The shadow tokens follow a progressive scale. Each level increases the blur radius, offset, and spread to create a stronger sense of elevation:

## Shadows Across Themes

Different themes give shadows a distinct character. The Futuristic theme uses subtle glows that complement its dark, high-contrast palette. The Cozy theme uses soft, diffused shadows that feel warm and approachable. The Artistic theme keeps shadows minimal, relying more on borders and whitespace for hierarchy.

## Dark Mode Shadow Considerations

Shadows behave differently on dark backgrounds. On light backgrounds, shadows are the primary depth cue. On dark backgrounds, shadows become nearly invisible because the background is already dark. NoorUI handles this through two complementary strategies:

1. **Border reinforcement**: In dark mode, components rely more heavily on `border-border` (a subtle dark gray) to delineate surfaces rather than shadows alone.
2. **Background lightness differentiation**: Card backgrounds (`--card`) are slightly lighter than the page background (`--background`) in dark mode, creating visual layers through surface lightness rather than shadow.

<CodeBlock
  filename="Dark mode elevation strategy"
  language="css"
  code={`.dark {
  --background: 222.2 84% 4.9%;   /* Very dark base */
  --card: 222.2 84% 4.9%;          /* Same or slightly lighter */
  --muted: 217.2 32.6% 17.5%;     /* Noticeably lighter for sunken areas */
  --border: 217.2 32.6% 17.5%;    /* Visible border to define edges */
}`}
/>

<DesignDecision title="Shadows Are Not the Only Depth Cue" type="tip">
  <p>
    {"Do not rely exclusively on shadow-* utilities for visual hierarchy. In dark mode, pair shadows with a lighter card background and a visible border. The combination of bg-card border border-border shadow-md reads as elevated in both light and dark modes."}
  </p>
</DesignDecision>

## Usage Patterns

<CodeBlock
  filename="Shadow usage examples"
  language="tsx"
  code={`{/* Resting card */}
<div className="bg-card border border-border rounded-lg shadow-sm p-6">
  Card content
</div>

{/* Elevated on hover */}
<div className="bg-card rounded-lg shadow-sm hover:shadow-md transition-shadow">
  Interactive card
</div>

{/* Floating dropdown */}
<div className="bg-popover border border-border rounded-md shadow-lg">
  Dropdown menu
</div>

{/* Modal dialog */}
<div className="bg-background border border-border rounded-lg shadow-xl">
  Modal content
</div>

{/* Inset input */}
<input className="bg-background border border-input shadow-inner rounded-md px-3 py-2" />

{/* Remove shadow */}
<div className="shadow-none">
  Flat element
</div>`}
/>
